Sept 2026 UI Redesign Project

Background

The app is essentially just the Grid, with inbuilt functionality (ActionBar/PaginationBar/etc) and Dojo DialogBox popups for Form editing etc. The current UI is provided by Dojo and GridX and is further customized by me in an earlier iteration.
I am using an LLM to first work on generating Architecture Documents with intent similar to ADRs (Architectural Decision Records) seeking to create a lightweight document-driven development env.
When the documents are finalized they shall be used to generate two CSS files to render the further customizations based upon our decisions. The first file will go on top of the style section (for CSS global vars etc.) and the next will be appended at the end and shall contain the bulk of the code.
Some of the documents/upcoming decisions refer to Accessibility and Keyboard shortcuts, which are going to be addressed in a separate proj which will eventually be merged into this one; so for now it remains out-of-scope
