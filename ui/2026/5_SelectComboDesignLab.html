UI Design Lab — Select / Combo Control

Working visual specification and state laboratory for Select / Combo controls.

Current design hypothesis: Select / Combo controls should share the restrained geometry of TextBox and Button controls. The control itself should communicate affordance primarily through its border, typography and dedicated disclosure indicator; persistent color should remain restrained.

6. Design Questions to Resolve

  1. What distinguishes a Select from a Combo / editable control?
  2. What is the final disclosure-indicator geometry?
  3. Should hover use the shared very-light Claro Blue treatment?
  4. How should the open control differ from focus-visible?
  5. What is the popup/menu surface treatment and elevation behavior?
  6. What are the Compact, Default and Comfortable heights?
  7. How should selected, hovered and keyboard-focused popup rows interact?
  8. How should long labels and overflow be handled?
  9. How should validation and disabled/read-only states be communicated?
  10. Which measurements should become shared control primitives?
